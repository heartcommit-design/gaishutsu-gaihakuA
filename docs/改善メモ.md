## 未対応

**G01 デモ中は「印刷」「バックアップ」のお知らせ帯を出さない**（未着手・方針未決定）
- 起きていること：デモデータを入れると、画面の上に赤いアラームの帯、17時の印刷のお知らせ、バックアップのお知らせの3本が並ぶ。初めて見る人には騒がしく見える。
- 案：デモデータが入っている間は、印刷とバックアップの帯を出さない（アラームの帯は出す）。

**G02 タブが9個あり、初めての人には多い**（未着手・方針未決定）
- 看護師が普段使うのは「外出・外泊中」「予定」「＋ 新規登録」。ほかのタブ（カレンダー・日別一覧・集計・患者台帳・タグ管理・設定）をどう見せるか。

**G03 予定を登録すると、患者台帳の「前回の外出」が未来の日時になる**（済（1.9.1））
- 起きていること：予定（出発が15分以上先）を登録したときも患者台帳の前回外出日時・回数が更新され、呼び出し欄に「前回 （未来の日時）」と出る。
- v1.9.0 ではデモデータの中だけで避けた。本来は、実際に出発（GO）したときに更新するのがよい。
- 1.9.1 で対応：予定の登録・修正では基本情報（氏名・ID・病棟・部屋・連絡先など）だけを台帳に入れ、前回外出日時・回数・前回の行き先・同行者は出発（GO／「内容を確認・変更して出発」）のときに更新する。GOの取消ではGO前の値に戻す。1.9.0 までに登録した予定は、出発時に回数を二重に足さない。テスト：tests/test_v191_plan_patient.py

**G04 病棟名・入院形態を設定で変えられるようにする**（保留）
- 今は病棟名（東1〜本3）がコードに書かれている。ほかの病院で使うときに必要。

**G05 実機（iPad の Safari）での確認**（継続）
- 時刻の選び方（15分刻み）、日付の欄が勝手に開かないこと、アラーム音、ホーム画面からの起動。テストは Chromium なので、iPad での確認は人が行う。

**H3 同意の撤回をボタンで**（済（1.11.0））

## 2.0.0 試作版（ブランチ shisaku-glass。指示書：作業指示書_試作版_v2.0.0）

現行（1.12.0）の機能はそのままに、見た目と「外出・外泊中」の現し方を新しくした試作版。現行の上書きではない。

**S1 現行と混ざらないための分離**（済（2.0.0））
- IndexedDB は `gaishutsu_kanri_shisaku`、キャッシュは `gaishutsu-shisaku-v2.0.0`。sw.js は `gaishutsu-shisaku-` で始まる自分の古いキャッシュだけを消す（現行の `gaishutsu-v…` は消さない）。
- manifest は「外出・外泊管理（試作）」「外出 試作」。ヘッダー・開始画面・「このアプリについて」に「試作版」。→ 2.0.1 で利用者に見える「試作」の表記はすべて外した（manifest は現行と同じ「外出・外泊管理」「外出管理」）。
- 現行のバックアップを読み込める。書き出すファイル名は「外出管理バックアップ_試作_日付.json」→ 2.0.1 で現行と同じ「外出管理バックアップ_日付.json」に戻した（中身の variant:"shisaku" は残す）。
- テスト：tests/test_v200_bunri.py

**S2 ガラス調の2配色（明るい／暗い）を全画面に**（済（2.0.0））
- 色は `:root` / `html[data-theme=dark]` の CSS 変数に寄せた。ガラスは `backdrop-filter`（blur・saturate・brightness）と半透明の面・内側ハイライト・細い縁・影だけ（SVG フィルタは使わない）。
- ぼかしはヘッダー・タブ・カード・パネル・ダイアログに限る。アラーム帯・予定超過・捜索中・音が出ない時のボタンは不透明のまま点滅・脈動。
- 印刷は配色に関係なく白地・黒文字・ガラスなし。
- テスト：tests/test_v200_haishoku.py（コントラスト比は画面上の実際の色から計算、両配色で 4.5 以上）、tests/test_v200_zengamen.py

**S3 昼夜の切り替え**（済（2.0.0））
- 設定「画面の明るさ」：自動（時刻で切り替え）／明るい／暗い。自動は暗くする時間帯（初期 18:00〜翌 7:00、30分刻みで変更可）。毎秒の見回りで、開いたまま切り替わる。
- ヘッダーの「画面：」ボタンで 自動→明るい→暗い。「透明感を弱める」でぼかしをやめる。
- 設定の本体は IndexedDB。最初の描画の前に配色を決めるため、配色の写しだけ localStorage（`gaishutsu_shisaku_theme`）に置く。

**S4 「外出・外泊中」を時間軸で**（済（2.0.0））
- 行は「タグ・氏名・状態｜時間軸｜残り時間・ボタン」。範囲は現在の2時間前（正時に切り下げ）から6時間、1時間ごとの目盛りと「現在」の線。毎秒は位置だけを動かし、行は作り直さない。
- 範囲の外は端で切り、入りきる時は切れた側に日時。予定超過は帰院予定から現在までを濃い色で継ぎ足す。
- 見出しの右に「時間軸／一覧」（一覧＝現行の行表示）。選んだ方を保存。スマホ幅（900px 以下）は軸を出さず、氏名の下に進み具合のバー。
- テスト：tests/test_v200_jikanjiku.py。画面写真：docs/screens_v2.0.0/（撮り直しは tests/make_screens_v200.py）

**S5 試作版で残っていること**（未着手）
- iPad の Safari 実機で、ぼかしの重さ・見え方・自動の切り替えを確かめる（G05 と同じく人が行う）。
- iPad 縦（1024px）では時間軸の列が約 200px と狭い（目盛りは2時間ごと）。右の列（残り時間・ボタン）を縮めるかは要相談。

**S6 試作版のホーム画面アイコン**（済（2.0.1））
- 現行（濃紺の地・金色の二重の輪）と一目で区別できるよう作り替え：青緑→青の斜めグラデーションの地に、ガラス風の板と時間軸の帯3本（白・白・琥珀）・「現在」の縦線、下に白い太字「外出」、右上に琥珀の札「試作」（2.0.1 で札は外した）。
- 作り直しは `python3 tools/make_icon.py`（4倍で描いて縮小。端末の日本語フォントを使い、外部から取り込まない）。manifest の背景色・テーマ色も #1f8fb8 に。
