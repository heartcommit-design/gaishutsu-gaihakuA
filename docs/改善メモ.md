## 2.1.0 アラーム音の有効／無効・音量0の表示・「このアプリについて」（ブランチ v2.1.0-alarm-oto）

**A1 ヘッダーの「アラーム音」ボタンで有効／無効を切り替える**（済（2.1.0））
- 有効のとき押す → アプリ内の確認ダイアログ（「試しに鳴らす」「やめる」「無効にする」）。無効のとき押す・赤い帯の「有効に戻す」→ 確認なしで有効に戻し、知らせて1回試し鳴らし。
- 無効の間：ヘッダーのボタンは赤・点滅で「🔇 アラーム音：無効」、全タブ共通で上に固定した赤い帯（閉じられない）、開始画面にも注意。アラーム帯に「（音は無効）」。
- 止める音：アラーム・再アラーム（alarm）、強い警告（alarmUrgent）、見守り確認の音（chime）。設定の「アラーム音を試す」も鳴らさず知らせる。画面の知らせ（アラーム帯・赤い表示・点滅・脈動・タイトルの切り替え）は変えない。
- 保存先は IndexedDB の設定（`soundOff`）。再読み込み後も保たれ、バックアップの書き出し・復元に乗る。
- 表示の優先順位：音が出ません（ブラウザが未許可）＞ 無効 ＞ 音量0 ＞ 有効。
- テスト：tests/test_v210_alarm_oto.py。画面写真：docs/screens_v2.1.0/（撮り直しは tests/make_screens_v210.py）

**A2 音量0なのに「アラーム音：有効」と出る不具合**（済（2.1.0））
- 音量0のときヘッダーは赤・点滅で「🔇 アラーム音：音量0（鳴りません）」。押すと説明（「設定を開く」「閉じる」）。設定の音量欄の下に、0のときだけ赤い注意。保存したらすぐヘッダーに反映。
- 要相談：「強い警告」の音は以前から音量の設定に関係なく最大で鳴る作り（tone の音量1固定）。音量0でも強い警告だけは鳴るため、説明のダイアログにその旨を書き添えた。音量0で強い警告も止めるかは未決。

**A3 「このアプリについて」に「ご意見・不具合」「このアプリの外部への発信について」**（済（2.1.0））
- もとの「ご意見・不具合」（黒田 優まで…）は、指定の文言に置き換えた（同じ見出しを2つ並べない）。スマホ幅では見出しを本文の上に置く。

## 2.4.0 実機（iPad）で出た指摘5つ（ブランチ v2.4.0-jikki-shiteki）

**J1 入れ忘れの知らせが、開いている画面（ダイアログ）の裏・下に出て分かりにくい**（対応中（2.4.0）・検品待ち）
